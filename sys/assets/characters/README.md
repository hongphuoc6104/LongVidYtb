# Visual Cast and Character Style

Under current guidance (Prompt Registry `1.1.0`, channel profile v5):
- **No fixed protagonist, no recurring presenter/host across scenes.**
- All characters belong to the **anonymous stick-figure cast**: large round white head with thick black outline, expressive dot/oval eyes, thin stick limbs, exactly one torso.
- The role of each character depends entirely on lesson context and script requirements (costume, props, hair, skin tone, age specified in visual brief).

## Active Style Assets
- `cast-style-sheet/`: Contains illustration reference sheets (Ink Explainer style, thick hand-drawn black ink/marker lines, flat color fills, edge-to-edge bright background).
