# Content & Script Strategy — Macro Gears (`en_macro_gears`)

## 1. Standalone Packaging & V4 Short Funnel
- **Title Contract:** `youtube_title <= 55` characters. Strictly NO numbered prefixes (`P1:`, `Part 2:`, `Ep 3:`) on Shorts.
- **Funnel Twin:** Shares verified primary Fact Vault research with sibling channel `banh_rang` (`./vp clone-en` / bilingual adaptation).
- **Short->Long Policy:** Declare `parent_long_id` when linked; place channel bridge + 2-choice debate question inside final `15%` (`youtube_closing_question` / pinned creator comment). Never say *"like/share/subscribe"*.
- **NotebookLM 3-Vault Grounding:** Compile verified primary sources into `fact_vault.json` via `sys/tools/notebooklm_vault.py` before drafting narration (`fact_grounding_linter.py --strict`).

## 2. Proven Narrative Spine (`Practical Engineering / Wendover`)
- **Sentence Structure Formula:** Công thức 5 bước Wendover / Practical Engineering: (1) Số liệu khoảng cách / quy mô choáng ngợp ('A seventeen-thousand-mile voyage...') -> (2) Đóng khung nghịch lý hiện đại ('is now completely routine...') -> (3) Đòn bẩy đối chiếu lịch sử / kỳ tích kỹ thuật ('Yet this massive container ship was once deemed impossible...') -> (4) Mô tả kích thước và tải trọng vật lý ('Stretching four football fields long, she carries...') -> (5) Kết luận mang tính hệ thống hạ tầng vĩ mô ('anchoring the fragile gears of global trade').
- **Long (`long_16x9`) Spine:** Cold open 0-30s: strongest scene of the video, no channel intro -> Stakes: why this matters to the viewer's own life -> 3-5 chapters, each opens with a mini-hook and ends with a re-hook -> Pattern interrupt every 20-30s (story, number, visual gag) -> Synthesis + practical takeaway -> Closing line pointing to the next video
- **Short (`short_9x16`) Spine:** Hook <= 3s: shocking claim or relatable pain + striking first frame -> Open loop: promise the answer, delay it -> Escalation beats every 2-5s (new visual, number or twist) -> Payoff: answer the loop in one clear image -> Closing line
- **20s Verbatim Rhythm Benchmark:** [00:00-00:05.5s] '...seventeen-thousand-mile, twenty-seven-thousand-kilometer voyage from America to Asia, and back.' [pause 0.50s] -> [00:06.0-00:13.1s] 'This is, in the context of today's ocean shipping industry, a rather unremarkable journey on a rather unremarkable ship.' [pause 0.94s] -> [00:14.0-00:17.8s] 'Just fifteen years ago though, the Maersk Essex would have been truly extraordinary.' [pause 0.18s] -> [00:18.0-00:20.0s] 'It measures four football fields long.'
