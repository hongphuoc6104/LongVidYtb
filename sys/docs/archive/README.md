# Historical & Trial Archive

This directory stores historical trial notes, performance benchmark logs, local environment patches, and layout restructuring reports from previous development phases (September 2026 and the 2026-10-03 normalization sprint).

> [!NOTE]
> Documents in this directory are **historical records**, not active operational guidance or system policies.
> Active operations are governed by `sys/docs/workflow.md`, `sys/docs/contracts.md`, and core documentation in `sys/docs/`.
