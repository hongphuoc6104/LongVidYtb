# Reference-led Hand-Drawn 2D Explainer (registry 1.7.0)

Use the user-supplied artwork as drawing-language references, not reusable subject matter. Exclude browser chrome, player controls, subtitles and watermarks. Do not claim a file was attached without provider evidence.

## Authoring

- Use clear black contours with slight natural irregularity, flat fills and minimal shading. White fields suit diagrams and isolated objects; contextual scenes use simple flat shapes.
- Each image explicitly declares `has_character`. `false` forbids human figures, hands and silhouettes; it does not prohibit an authored animal. `true` permits only the described contextual people. Identity references are optional and scoped to actual continuity requirements.
- Do not add CH01 by default or register unused characters. An entirely object-based job can have `characters: []`.
- A `full_scene` is a complete composition, including object-only compositions. A `variation` may change objects or diagrams; lock facial expression only when an actual person is present.
- Each new image authors `explanation` with an exact narration `quote`, explanatory `relation`, source terms occurring in that quote and visual terms occurring in the description. These bindings establish traceability, not measured semantic accuracy. Inspect the generated image against the explanation.
- Static compositions are valid when quantities, grouping, comparisons or causal relations explain the narration. Do not require high-velocity action, room furnishings or a minimum share of people/no-people frames.
- These comparison shorts have five scenes, 45–60 measured seconds, VietNarrator at speed 1.0 and portrait subtitles. Do not pad, accelerate or truncate to conceal a script mismatch.

## References and dispatch

- Style, character identity and Base composition have different meanings. Respect the actual provider attachment limits. A Character UI slot used for style does not authorize an invented identity.
- Include exact reference bytes/media provenance in cache identity. Foreign project media IDs are not portable across profiles; upload a local reference through a verified supported path or stop with the missing capability.
- New pool-mode jobs schedule only accounts authorized by the frozen management session. Keep each existing Base chain on its verified owner, serialize shared UI operations within a profile, and demonstrate real overlapping dispatch intervals before claiming concurrency.
- Missing sockets, image files and transport-error wording never prove a provider request was not submitted. Retain ambiguous ownership and reconcile/collect before another generation.

## Acceptance

Technical tests do not certify drawing style. Inspect genuine generated samples for outline, flat fills, background, exact entities, readable labels and explanatory meaning before producing a full batch. Verify actual remote WAV/MP4 duration, subtitles and current input revisions. Report downloaded scene images separately from reference and registration resources.
